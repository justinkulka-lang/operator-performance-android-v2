Install the debug APK over a copy of the current v7.1 build only on a test profile. Confirm:

1. Fresh install shows START WEEK 1 • DAY 1 and opens Week 1 Day 1 Engine baseline with no short upper.
2. An initialized mid-week v7.1 pointer, for example Week 2 Day 3 with or without an in-progress workout, still shows the v7.1 session and the "FINISHING THIS WEEK UNDER v7.1" line. The next Day 1 is v7.2.

4. START and RESUME stay visible without scrolling the session. Large font and display size still show the full session. The day dialog scrolls to the last coaching line.
5. Dark theme remains readable.
6. Rotate the device during a rest timer, kill the process, and reboot. The timer end and the session pointer return.
7. Week 12 Speed shows the 600 m workload warning. Week 14 Speed does not.
8. Week 32 Day 2 and Day 6 are bike and mobility. Day 5 has no easy aerobic. Day 7 says the program is complete and does not offer Day 1 of Week 33.
9. Tools export does not ask for loads, reps, pace, or bodyweight. Airplane mode still opens every session.
